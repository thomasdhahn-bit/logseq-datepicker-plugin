# Logseq Datepicker Plugin

Dieses Plugin fügt in Logseq oben rechts ein Kalender-Icon in der Toolbar hinzu.
Beim Klick öffnet sich ein Datepicker, mit dem du direkt zum entsprechenden Journaleintrag springen kannst.

## Installation

1. Dieses Repository klonen oder herunterladen.
2. In Logseq unter **Settings → Advanced → Developer mode** aktivieren.
3. **Plugins → Load unpacked plugin** und den Ordner dieses Repos auswählen.

## Verwendung

1. Klicke oben rechts auf das Kalender-Icon.
2. Wähle ein Datum aus.
3. Klicke auf **Zum Eintrag springen**.

Das Plugin nutzt dein in Logseq konfiguriertes Datumsformat (`preferredDateFormat`) für den Journalseitennamen.
